RabbitMQ 概述

Created2026-06-17|Updated2026-06-17|RabbitMQ
|Post Views:

RabbitMQ 使用 Erlang 语言开发的开源消息队列系统，基于 AMQP 协议实现。

概述

1. 优势

  • 开源、性能优秀，稳定性保障
  • 提供可靠消息投递模式(confirm)、返回模式(return)
  • 与 Spring AMQP 成熟集成
  • 集群模式丰富
  • 保证消息不丢失的前提做到高可靠性、可用性

2. AMQP 高级消息队列协议

AMQP(Advanced Message Queuing Protocol 高级消息队列协议) 是具有现代特征的二进制协议。提供统一消息服务的应用层标准高级消息队列协议。为面向消息中间件设计的应用程开发标准协议。

2.1 AMQP 核心概念

  • Server: 又称 Broker 接受客户端连接，实现 AMQP 实体服务（每个 RabbitMQ 服务器都是一个 Broker ）

  • Connection: 连接，应用程序与 Broker 的网络连接

  • Channel: 网络信道，代表一个消息会话，对消息的读写都是在 Channel 中进行，一个客户端可以有多个 Channel

  • Message: 消息，服务器与应用程序之间传递的数据，由 Properties 和 Body 构成

    • Properties 消息属性（优先级、延迟等高级特性）
    • Body 消息体内容

  • Virtual host: 虚拟主机，用于逻辑隔离最上层的消息
    一个 Virtual Host 可以有若干个 Exchange 和 Queue 并且不能重复；不同的 Virtual Host 可以用来隔离不同的微服务域。

  • Exchange: 交换机，接收消息并根据路由键转发消息到绑定的队列

  • Binding: Exchange(交换机)和Queue(队列)之间的虚拟连接， Binding 中可以包含 routing key

  • Routing key: 用来确定交换机到队列之间的路由规则

  • Queue: 也成为 Message Queue(消息队列)，实际保存消息并将消息转发给消费者

3. 命令行工具

rabbitmqctl 服务管理
rabbitmq-server 服务管理
rabbitmq-plugins 插件管理

3.1 rabbitmq-server

  • 前台启动服务: rabbitmq-server start

3.2 rabbitmqctl

  • 启动服务: rabbitmqctl start_app

  • 关闭服务: rabbitmqctl stop_app

  • 查看节点状态: rabbitmqctl status

  • 添加密码为 ##password## 的 ##username## 用户: rabbitmqctl add_user _##username##_ _##password##_

  • 查看系统内所有用户: rabbitmqctl list_users

  • 删除 ##username## 的用户: rabbitmqctl delete_user _##username##_

  • 清理 ##username## 用户对虚拟主句 ##vhostpath## 的权限: rabbitmqctl clear_permissions -p _##vhostpath##_ _##username##_

  • 查看用户 ##username## 的权限: rabbitmqctl list_user_permissions _##username##_

  • 修改 ##username## 用户密码为 ##new-password##: rabbitmqctl change_password _##username##_ _##new-password##_

  • 设置权限: rabbitmqctl set_permissions -p _##vhostpath##_ _##username##_

  • 创建虚拟主机: rabbitmqctl add_vhost _##vhostpath##_

  • 查看所有虚拟主机: rabbitmqctl list_vhosts

  • 查看虚拟主机的权限: rabbitmqctl list_permissions -p _##vhostpath##_

  • 删除虚拟主机: rabbitmqctl delete_vhost _##vhostpath##_

  • 查看所有队列: rabbitmqctl list_queues

  • 清空队列中的消息: rabbitmqctl -p _##vhostpath##_ purge_queue _##queue##_

  • 清理所有数据(要在 rabbitmqctl stop_app 之后使用): rabbitmqctl reset

  • 加入集群: rabbitmqctl join_cluster _##clusternode##_ [--ram]

  • 查看集群状态: rabbitmqctl cluster_status

  • 修改集群节点的存储形式: rabbitmqctl change_cluster_node_type disc|ram

  • 摘除节点: rabbitmqctl forget_cluster_node [--offline]

  • 修改节点名称: rabbitmqctl rename_cluster_node oldnode1 newnode1 [ oldnode2 newnode2 ...]

3.3 rabbitmq-plugins

  • 启用管理插件：rabbitmq-plugins enable rabbitmq_management
  • 启用 STOMP 插件: rabbitmq-plugins enable rabbitmq_stomp
  • 启用 STOMP web 插件: rabbitmq-plugins enable rabbitmq_web_stomp
